# Organizing Products

## What it does

These screens group your products so shoppers can find them and so you can manage them in bulk: **Categories**, **Collections**, **Brands**, **Tags**, **Attributes** and **Product Types**. They are all under **Products** in the admin menu.

## Why it matters

Shoppers filter the shop by category. Brands and collections appear on product pages. Attributes (size, colour) are what variants are built from.

## Categories, collections, brands and tags

All four screens work the same way.

| Screen | Use it for |
|---|---|
| **Categories** | What kind of product it is. Categories can be nested (a parent and children) |
| **Collections** | Hand-picked groups, such as "Summer sale" |
| **Brands** | Who makes the product. A brand can have a logo |
| **Tags** | Free-form labels |

To add one:

1. Go to **Products → Categories** (or Collections, Brands, Tags).
2. Fill in the form: **Name** (required, "how it appears across your store"), **Slug** (the URL-friendly version; leave it blank to create it from the name) and, for categories, a **Parent** (nest it under another category to build a hierarchy). **Description** is optional and is shown on some storefront layouts.
3. Press **Add new**. The entry appears in the list on the other side of the screen.

The list shows how many products use each entry. Use the filters **All**, **In use** and **Empty** to find entries nobody uses. **Search by name or slug** to find one. **Edit** changes it; **Delete** removes it after you confirm. You can select several entries and use **Delete selected**.

Then assign them on a product, in its **Catalog & Sourcing** card.

## Attributes

An attribute is a named property products can be described by, for example **Color** with the values Red, Blue and Green.

1. Go to **Products → Attributes** and press **Add attribute**. Give it a name (for example "Color").
2. Press **Manage values** and add the values one at a time. Remove a value with **Remove value**.
3. Deleting an attribute deletes all its values.

Attributes are used to generate variants of a product (VuloCart Pro, module *Variants*).

## Product types

**Products → Product Types** lists the kinds of product VuloCart supports with the number of products of each. Switch off the types you never sell: they are no longer offered when you create a product. Existing products of that type keep working. At least one type must stay on.
