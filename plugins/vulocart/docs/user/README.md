# VuloCart User Guides

Plain-language guides for store owners. Each guide first explains **what a feature does and why it matters**, then shows **how to use it** and explains every setting. Read **Getting Started** once; the other guides do not repeat installation.

Looking for code-level detail? See [../developer](../developer/README.md). Using VuloCart Pro? See the [Pro guides](../../../../../plugins/vulocart-pro/docs/user/README.md).

## Read in this order

```
1. GETTING-STARTED  ──►  2. PRODUCTS  ──►  3. PAYMENTS, SHIPPING-AND-TAX  ──►  4. CHECKOUT  ──►  5. Everything else
```

| Step | Guide | Use it to |
|---|---|---|
| 1 | [GETTING-STARTED](GETTING-STARTED.md) | Install, learn the menu, get your first sale |
| 2 | [PRODUCTS](PRODUCTS.md) | Add products, prices, stock and photos |
| 3 | [PAYMENTS](PAYMENTS.md), [SHIPPING-AND-TAX](SHIPPING-AND-TAX.md) | Decide how you get paid, what shipping costs and how tax is charged |
| 4 | [CHECKOUT](CHECKOUT.md) | Put the shop, cart and checkout on your pages and tune the checkout |

## How every guide is built

1. **What it does** - the feature in plain words.
2. **Why it matters** - what you gain, or risk, if you ignore it.
3. **How to use it** - numbered steps.
4. **Settings explained** - what each setting does and why you might change it.
5. **Related** - where to go next.
