# VuloForm user guide

VuloForm lets you build forms by dragging fields onto a page, put them on your site, and read what people send.

| Guide | Read it when you want to |
| --- | --- |
| [GETTING-STARTED.md](GETTING-STARTED.md) | Publish your first form in a few minutes |
| [BUILDING-FORMS.md](BUILDING-FORMS.md) | Use the builder: add, arrange and set up fields |
| [FIELDS.md](FIELDS.md) | Know what each field type does |
| [CONDITIONAL-LOGIC.md](CONDITIONAL-LOGIC.md) | Show, hide or require a field depending on an answer |
| [PUBLISHING.md](PUBLISHING.md) | Add a form to a page, or to a different website |
| [SUBMISSIONS.md](SUBMISSIONS.md) | Read, search, export and delete what people sent |
| [NOTIFICATIONS-AND-WEBHOOKS.md](NOTIFICATIONS-AND-WEBHOOKS.md) | Get an email or text, confirm to the sender, send data to another service |
| [SETTINGS-AND-PRIVACY.md](SETTINGS-AND-PRIVACY.md) | Control how long data is kept and what is stored |
| [TROUBLESHOOTING.md](TROUBLESHOOTING.md) | Fix something that is not working |

You need to be an administrator of the site to use VuloForm.
